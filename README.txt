MAVEN CONNECT — INSTALLABLE PWA STARTER
Creator credit: by barackmarverick

This is a front-end demo, not yet a live messaging service. Demo messages are stored only in this browser/device. Real accounts, phone verification, cross-user delivery, and end-to-end encryption are not implemented yet.

A PWA must be hosted on HTTPS (or localhost) to install. Opening index.html directly from Downloads is not enough.

Free install route:
1. Extract this ZIP while keeping its folder structure.
2. Upload all files to a free static HTTPS host, such as GitHub Pages.
3. Open the hosted HTTPS URL in Chrome on Android.
4. Tap Chrome ⋮ > Install app or Add to Home screen, then confirm.
5. On iPhone, open the same URL in Safari > Share > Add to Home Screen > Add.

This does not publish the app to Google Play or Apple's App Store. Store distribution has separate requirements and potential fees.
